# Credenzo

**The taste test for agent tools.** Credenzo (formerly mcp-audit) is an offline security scanner and committable lock for the MCP servers your AI coding tools run.

The rename is in progress. This package installs [`mcp-audit-scanner`](https://pypi.org/project/mcp-audit-scanner/), which holds the code. The command is `mcp-audit`.

Source and documentation: https://github.com/adudley78/mcp-audit
